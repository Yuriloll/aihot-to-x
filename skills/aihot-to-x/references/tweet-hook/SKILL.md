# Embedded tweet-hook

这是 `aihot-to-x` 内嵌的作者自制 `tweet-hook` Skill。它只负责开头钩子，不替代事实核验、来源判断和字符校验。

先从已核验事实中找一个真实的冲突、变化、代价、立场或信息缺口，再写一句能让读者继续看的开头。优先使用：制造矛盾、制造焦虑、制造话题、制造热度、抛出钩子，也可以组合两种。

钩子后马上兑现事实，不能用空泛的“重磅”“炸裂”撑场；没有可靠数字就不写数字；没有证据就不写因果和影响。中文开头尽量在前 12—20 字出现冲突或缺口，少用产品说明书口吻。

每条新闻只写一个版本，结构为“钩子 + 关键事实 + 明确判断”。判断必须能从来源推出；推不出来就删掉。QT 与链接帖的字符上限、来源保留和人工审核要求，以上一级 `SKILL.md` 为准。
